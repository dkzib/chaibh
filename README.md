# Mini Cash

Mini Cash — Telegram-бот для учета продаж чая. Он помогает вести каталог, оформлять заказы, фиксировать способы оплаты и просматривать отчеты.

## Запуск

1. Установите зависимости:

   ```powershell
   .\venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота и список разрешенных пользователей.
3. Запустите бота:

   ```powershell
   .\venv\Scripts\python.exe .\main.py
   ```
